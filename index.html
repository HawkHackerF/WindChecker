Windows forensic triage

See what really happened on a Windows machine.

WindChecker is a single-file workbench for Windows forensics. Thirty-nine modules read live system state and on-disk artifacts — processes, services, event logs, USN journal, MFT, USB history, SRUM, notifications, file hashes and image metadata — and show every record with the raw detail behind it.

Modules

Grouped the way an investigation moves: the host, the file system, the network, then execution and persistence artifacts. Every module shares the same table, filter bar and detail pane.

Requirements and scope

WindChecker reads a machine that is already running. It does not replace a write-blocked acquisition or a full disk imager.

Operating systemWindows 10 or Windows 11, 64-bit
PrivilegesAdministrator for most artifacts; some modules show only what the current user can read
FootprintOne executable, no installer, no service, no driver
NetworkNot required — nothing is uploaded
WritesNone by default; carving writes only to the destination you choose
Intended use Built for authorized forensic examination, incident response and security testing on systems you own or have written permission to examine. Several modules read sensitive artifacts, so handle the output like any other evidence.
